One line of famous last words, carved as a tombstone epitaph, written for the make.fun competition
**Famous Last Words: The Funniest Epitaph** (pot $2, top 2).

The entry program writes a single 22-character line to `/output/entry.txt`:

> I told you I was sick.

Run it with `python3 main.py` (or `MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py`).
